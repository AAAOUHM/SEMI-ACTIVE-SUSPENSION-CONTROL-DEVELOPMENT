This project is on semi-active vibration control of A seat suspension system by using an MR (Magneto rheological ) damper. This project is done for UNO MINDA company in association with IIT MADRAS.
The project is done is phases , where first system modelling and identification is done. 
Next we have  tuned our Skyhook controller to meet desired Transmissibility(amplification ratio) curves from simulating the frequency response curve for different road disturbances. Next we have pplan to use some realistic model for like Buoc wen model for our MR damper.
